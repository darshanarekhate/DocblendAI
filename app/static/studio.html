              What goes in the .zip?
              
            A labels.csv with the columns image,text, plus the images it names (paths relative to the zip root).
                text is the correct transcription of the image, one line of text per line (put the cell in quotes when it spans several lines).
                Each image is read with Text OCR; a line counts as correct when it matches the transcription, and the calibrator learns how often each confidence level is right.
