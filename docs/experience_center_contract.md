# Experience Center: API and module contract

Shared interface between the PaddleOCR service/API (`app/modules/paddleocr_service.py`,
`app/routers/paddleocr.py`), the calibration package (`app/calibration/`) and the
Experience Center UI (`app/static/studio.*`, served at `/studio`). Change this file
together with the code when an interface changes.

Settings live in `app/config.py` (block "PaddleOCR Experience Center").

## 1. Calibration package (`app/calibration/`)

Pure numpy (no scikit-learn, no matplotlib). Confidences are floats in [0, 1]; labels are
1 = the OCR line was read correctly, 0 = not.

```python
from app.calibration import (
    Calibrator,            # base class
    TemperatureScaler, PlattScaler, IsotonicCalibrator,
    fit_and_select,        # (confidences, labels, val_fraction=0.3, seed=0) -> (Calibrator, report: dict)
    load_active,           # () -> Calibrator | None   reads settings.paddle_calibration_dir / "calibrator.json" (cached)
    clear_active_cache,    # () -> None                call after writing a new calibrator
    calibrate_confidences, # (list[float]) -> tuple[list[float], str]   status "calibrated" | "uncalibrated"
)
from app.calibration.metrics import ece, mce, brier, nll, reliability_bins
from app.calibration.calibrate import run_calibration
# run_calibration(dataset: Path, ocr_fn, out_dir: Path | None = None, match="cer",
#                 cer_threshold=settings.calibration_cer_threshold, progress=None) -> report dict
#   dataset: a folder holding labels.csv (columns image,text; text = ground-truth lines joined by "\n";
#            image paths relative to the folder) OR a path to such a CSV.
#   ocr_fn(image_path: Path) -> list[tuple[str, float]]   (line text, raw confidence)
#   progress(done: int, total: int) -> None   optional callback
#   Writes out_dir/calibrator.json, out_dir/report.json, out_dir/reliability_diagram.png
#   (out_dir defaults to settings.paddle_calibration_dir) and calls clear_active_cache().
```

`Calibrator` API: `.method` (`"temperature" | "platt" | "isotonic"`), `.fit(conf, labels)`,
`.predict(conf) -> np.ndarray`, `.to_dict()`, `Calibrator.from_dict(d)`.

`report.json` shape (also returned by `GET /api/calibration`):

```json
{
  "method": "isotonic",
  "selected_by": "validation ECE",
  "fitted_at": "2026-10-01T22:00:00+00:00",
  "dataset": "evaluation/calibration_sample",
  "match": "cer", "cer_threshold": 0.1,
  "n_lines": 120, "n_correct": 95, "n_train": 84, "n_val": 36,
  "candidates": {"temperature": {"val_ece": 0.05}, "platt": {"val_ece": 0.04}, "isotonic": {"val_ece": 0.03}},
  "metrics": {
    "before": {"ece": 0.08, "mce": 0.2, "brier": 0.14, "nll": 0.45},
    "after":  {"ece": 0.03, "mce": 0.1, "brier": 0.12, "nll": 0.39}
  },
  "bins": {
    "before": [{"lo": 0.0, "hi": 0.1, "count": 0, "mean_confidence": null, "accuracy": null}],
    "after":  [...]
  },
  "diagram": "reliability_diagram.png"
}
```
Metrics/bins are computed on the validation split (10 equal-width bins).

Bundled sample dataset: `evaluation/calibration_sample/` (labels.csv + PNGs), regenerated by
`venv/Scripts/python -m app.calibration.make_sample`.
CLI: `venv/Scripts/python -m app.calibration.calibrate [DATASET] [--match exact|cer] [--cer-threshold 0.1] [--out DIR]`.

## 2. PaddleOCR service (`app/modules/paddleocr_service.py`)

- `paddleocr_service` singleton; models lazy-loaded once per (pipeline, language), thread-safe.
- Imports `torch` before `paddle`/`paddleocr` when torch is installed (Windows DLL clash: paddle
  first makes torch fail with WinError 127 in shm.dll; TrOCR/docTR share this process).
- Sets `os.environ.setdefault("PADDLE_PDX_DISABLE_MODEL_SOURCE_CHECK", "True")` before importing paddleocr.
- Always passes `enable_mkldnn=settings.paddle_enable_mkldnn`, `device=settings.paddle_device`.
- Text OCR uses `rec_texts`/`rec_scores`/`rec_polys` (NOT `dt_polys`: it is not index-aligned with
  rec_texts once low-score lines are dropped) and `return_word_box=True` for word boxes.
- PDFs rendered with PyMuPDF at `settings.paddle_pdf_dpi`, at most `settings.paddle_max_pages` pages.
- `paddleocr_service.recognize_lines(image_path, lang="en") -> list[tuple[str, float]]`: text OCR of one
  image, (line text, raw confidence) in reading order. Used by `python -m app.calibration.calibrate`.
- Pipelines: `"ocr"` (PaddleOCR), `"structure"` (PPStructureV3), `"vl"` (PaddleOCRVL; only when
  `settings.paddle_enable_vl`, otherwise unavailable with a clear message), `"office"`
  (docx/xlsx/pptx -> Markdown via `paddleocr.doc2md_convert`, no OCR).

## 3. HTTP API (`app/routers/paddleocr.py`, prefix `/api`)

| Method | Path | Notes |
|---|---|---|
| GET | `/api/health` | `{status, engine: {paddleocr, paddlepaddle, ocr_version, device}, pipelines: {ocr, structure, vl, office: {available: bool, message}}, calibration: {status, method}, review_threshold, max_upload_mb, languages: [{code, name}]}` |
| POST | `/api/ocr` | multipart: `file`, `language`=en, `wait`=false, `review_threshold` (optional float), `preprocess` (optional JSON string, see §5). 202 `{id, status}` (200 + full result when wait=true) |
| POST | `/api/parse` | same fields + `pipeline` = `structure` (default) \| `vl`. Office files (docx/xlsx/pptx) on either endpoint run pipeline `office` |
| GET | `/api/results/{id}` | job/result object (§4); 404 if unknown |
| GET | `/api/results` | history: `?q=&limit=50` -> `[{id, filename, pipeline, language, status, created_at, page_count, mean_confidence, processing_time_ms}]` newest first |
| DELETE | `/api/results/{id}` | removes row + page images |
| PATCH | `/api/results/{id}/lines` | human review: `[{"page": 0, "line": 3, "text": "fixed"}]` -> updated result; edited lines get `"edited": true` |
| GET | `/api/results/{id}/pages/{n}/image` | PNG of page n as OCR'd (coordinates of boxes are in this image's pixels) |
| POST | `/api/calibrate` | multipart: `file` (.zip holding labels.csv + images) OR form `use_sample=true`; optional `match`, `cer_threshold`. 202 `{id, status}`; job result = report (§1) |
| GET | `/api/calibration` | current report (§1) or `{"status": "uncalibrated"}` |
| GET | `/api/calibration/diagram.png` | reliability diagram; 404 if none |

Errors: `{"detail": "..."}` with 400 (bad form values), 404, 413 (too large), 415 (bad type), 503 (engine/pipeline unavailable).

Details fixed by the implementation (additions, nothing above changed):
- `wait=true` on a job that fails returns 200 with `status: "error"` and `error` set, except a pipeline
  that cannot load (503). DELETE / PATCH on a run that is still running: 409.
- Calibration jobs (`POST /api/calibrate`) are polled with `GET /api/results/{id}` too; they are not in the
  history list and return `{id, status, progress, message, error, pipeline: "calibration", language,
  filename, created_at, processing_time_ms, report}` (`report` = §1 report once done, else null).
- `GET /api/calibration` returns the §1 report plus `"status": "calibrated"`.
- PATCH: edited lines also get `needs_review: false` (a human checked them); `summary` is recomputed and,
  for `pipeline: "ocr"`, the page and result `markdown` are rebuilt from the lines.
- History `mean_confidence` = mean calibrated confidence (null for office runs). Runs left `queued`/`running`
  by a server restart are reported as `status: "error"`.

```json
{
  "id": "hex32", "status": "queued|running|done|error", "progress": 0.0, "message": "Page 2 of 5",
  "error": null,
  "pipeline": "ocr|structure|vl|office", "language": "en", "filename": "scan.pdf",
  "created_at": "2026-10-01T22:00:00+00:00", "processing_time_ms": 1234.5,
  "calibration": {"status": "calibrated|uncalibrated", "method": "isotonic|null", "review_threshold": 0.7},
  "summary": {"page_count": 2, "line_count": 40, "mean_raw_confidence": 0.93, "mean_calibrated_confidence": 0.88, "needs_review": 3},
  "markdown": "# Title\n\n...",
  "pages": [{
    "index": 0, "width": 1240, "height": 1754,
    "image_url": "/api/results/<id>/pages/0/image",
    "lines": [{
      "id": "p0-l3", "text": "Hello", "polygon": [[x, y], [x, y], [x, y], [x, y]], "box": [x0, y0, x1, y1],
      "raw_confidence": 0.98, "calibrated_confidence": 0.91, "needs_review": false, "edited": false,
      "words": [{"text": "Hello", "box": [x0, y0, x1, y1]}]
    }],
    "markdown": "...",
    "blocks": [{"type": "doc_title|paragraph_title|text|table|figure|formula|...", "box": [x0, y0, x1, y1], "content": "..."}],
    "tables": [{"box": [x0, y0, x1, y1], "html": "<table>...</table>", "rows": [["Method", "ECE"], ["Raw", "0.08"]],
                "cells": [[x0, y0, x1, y1]]}]
  }]
}
```
`pipeline: "ocr"` fills `lines` (blocks/tables empty, markdown = lines joined). `structure`
fills all of them (`lines` from `overall_ocr_res`). `office` has no image: `width/height/image_url`
are null and only `markdown`/`tables` are filled. While `status != "done"`, `pages` may be `[]`.

## 5. Preprocessing options (`preprocess` JSON on /api/ocr and /api/parse)

`{"deskew": bool, "denoise": bool, "contrast": bool, "binarize": bool}`, all default false.
Applied in that order to every rendered page image before recognition (not to Office files);
the stored page image is the cleaned one, so boxes line up with what the UI shows. Results list
the applied steps in `"preprocess": ["deskew", ...]`.

## 7. Shared documents, automatic LLM refinement, versions

**One upload, one document for both pages.** `POST /upload` (QA page) and `POST /api/ocr` /
`/api/parse` (Experience Center) store the file in `data/uploads/`, and one background run does:
"Extracting page 2 of 5…" (document_extract.py: exact text for typed PDF / docx / pptx / xlsx /
txt; PaddleOCR or PP-StructureV3 for scans and images; TrOCR reading Paddle's line boxes for
handwriting) → "Refining with Gemini…" (every line, `refine` plugin, changes applied at once) →
"Indexing for questions…" (chunks, calibrated confidence, content types, embeddings) → "Ready".
The run is linked to the QA `Document` (`document_runs` table); deleting either deletes both.
If Gemini is unavailable (no key, quota, error) the unrefined text is used, QA is not blocked, and
`refinement.status` is `unavailable` with a message.

`POST /upload` waits by default (201 Document, as before); `background=true` returns 202
`{doc_id, run_id, status}`. Optional `pipeline` = structure (default, `INGEST_PIPELINE`) | ocr.

| Method | Path | Notes |
|---|---|---|
| GET | `/documents/library?q=` | both pages' documents: `{doc_id, run_id, name, format_type, page_count, status: processing\|ready\|error, progress, message, error, qa, refinement, refine, pipeline, engine, created_at, mean_confidence, qa_ready}` |
| POST | `/documents/{doc_id}/experience` | read an earlier QA upload into a run (202 `{run_id}`) |
| GET | `/api/results/{run_id}/changes` | what Gemini proposed per line (read-only): `{id, seq, kind: "refinement", data: {model, max_change, counts, lines: [...]}}`; 404 if not refined |
| POST | `/api/results/{run_id}/revert` | use the original extraction (QA re-embedded) -> result |
| POST | `/api/results/{run_id}/reapply` | use the latest LLM-refined text again (no Gemini call) -> result |
| POST | `/api/results/{run_id}/refine` | retry the refinement of the original extraction: 202 `{job_id}`; poll `/api/results/{job_id}` (`pipeline: "refine"`). 503 without `GEMINI_API_KEY`, 409 while one runs |
| GET | `/api/results/{run_id}/versions` | `[{id, seq, kind: extraction\|refinement\|edit\|restore, label, created_at, counts?}]` oldest first |
| GET | `/api/results/{run_id}/versions/{version_id}` | the version with its `data` (a result object, or a proposal) |
| GET | `/api/results/{run_id}/versions/{version_id}/compare` | `{version, changes: [{line_id, page, before, after, status, diff?}]}` to the current text |
| POST | `/api/results/{run_id}/versions/{version_id}/restore` | make it current (recorded as a new version) -> result |
| GET | `/api/results/{run_id}/export/layout` | layout-preserving monospace text (`<name>.layout.txt`) |

Versions of a refined upload: v1 "Original extraction", v2 "Gemini's proposal (n changes)",
v3 "Refined by Gemini (n corrections)" (current). Nothing is ever overwritten.

Result additions: `doc_id`, `format_type` (typed | scanned | handwritten), `engine`, `notes`,
`qa: {status: ready | stale, chunks, message, indexed_at}`,
`refinement: {status: refined | unavailable | reverted | off | empty, message, model, corrected, counts, proposal_version, original_version}`,
`active_job` (a running retry, or null).

Line additions: `source` = how the text was read (`text` typed, `paddleocr`, `trocr`, `tesseract`)
or changed (`llm`, `human`); refined lines also carry `ocr_text` (as recognised), `llm_diff`
(`[{op: equal|replace|insert|delete, original, refined}]`) and `llm_status` (corrected | inferred).
A line whose refinement would change more than `REFINE_MAX_CHANGE` (0.4) of its characters keeps
its text and gets `llm_flag` + `needs_review: true`. In the QA index, LLM-changed text counts at
most `reliability.LLM_TEXT_MAX_CONF` (just below Certain): answers resting on it are at most Moderate.
